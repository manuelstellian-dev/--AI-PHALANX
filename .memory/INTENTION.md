# INTENTION — why ΛΕΩΝΙΔΑΣ-AI PHALANX exists

> Root node of the memory graph. Every other entry must trace back here (validator rule M13).
> Changing an intention is a Commander-level decision (LAW-005).

### INT-001 · A sovereign, autonomous AI decision core for high-stakes operations
- **status:** active
- **evidence:** README.md, ARCHITECTURE.md, core/leonidasbrain.py

Build an AI decision core that can be trusted where error means harm: military, medical,
critical-infrastructure and security operations. It runs under a Spartan military architecture:
the **Λ-Core** commands, the **Phalanx** keeps internal order and the **Hoplites** act (ONT-001,
ONT-002, ONT-003). It serves one **Commander** (ONT-017) with absolute loyalty and operational discipline.

### INT-002 · Truth over fluency — never invent
- **status:** active
- **evidence:** docs/sparta/SPARTA_OVERVIEW.md, sparta/reflexive_generator.py

The defining failure of conventional language models is confident fabrication. ΛΕΩΝΙΔΑΣ reasons
by logical traversal of a curated Foundation of verified concepts (SPARTA, ONT-008). It does not
predict tokens. It must know what it knows, admit what it does not know, and never present an
unverifiable claim as verified (LAW-007).

### INT-003 · Homeostasis, and a compromise that yields nothing
- **status:** active
- **evidence:** phalanx/helot.py, phalanx/thermopylae.py

The system keeps itself in balance (dS/dt = 0). Its rhythm comes from the Autonomous Spartan Time
Λ-TAS (ONT-004), which is driven by measured parallelism and workload. If its survival is genuinely
threatened, the Thermopylae protocol destroys every secret, so a captured system yields nothing of
value (LAW-011).

### INT-004 · Sovereignty — own models, no external dependence at runtime
- **status:** active
- **evidence:** logos/model.py, tests/test_logos.py

The system depends on no external model, external API or network service to think. Its embedding
model, Λ-Logos (ONT-014), is built in this repository and trained on the project's own knowledge.
This is what makes the mandatory air-gap (LAW-009) more than a configuration flag (LAW-006, DEC-012).

### INT-005 · Continuity — the project accumulates understanding, not only code
- **status:** active
- **evidence:** .memory/README.md, mnemosyne/graph.py

Work is done across many sessions and by many agents, human and AI. Without a persistent, verifiable
memory, each session must rediscover the vision, re-derive decisions and guess the current state.
That is context collapse. The `.memory/` graph is the project's canonical, machine-checkable memory:
intention, identity, laws, decisions, state, checkpoints and extensions (DEC-014).

### INT-006 · Desired end-state
- **status:** active
- **cites:** INT-001, INT-002, INT-003, INT-004, INT-005

A deployable, air-gapped decision core in which:

1. every answer is grounded in verified knowledge, with its sources and reasoning (SPARTA plus the
   seven Λ-Modules, ONT-019);
2. every module behaves as documented, with no simulated components left (see EXT entries);
3. cryptography is post-quantum ready and keys are managed;
4. every state of the project is verified, checkpointed and explainable from this memory.

Progress toward this end-state is tracked in CURRENT_STATE (STATE-001).
