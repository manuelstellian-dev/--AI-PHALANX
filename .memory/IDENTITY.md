# IDENTITY — who the project is

> The self-model. INTENTION says *what* is built; IDENTITY says *how it thinks and behaves*.
> It guides qualitative judgment where no law applies.

### IDN-001 · Name, motto and governing metaphor
- **status:** active
- **cites:** INT-001

**ΛΕΩΝΙΔΑΣ-AI PHALANX** (Leonidas-AI Phalanx). Motto: **ΜΟΛΩΝ ΛΑΒΕ** ("Come and take them").
The Spartan city-state is the architecture, not decoration. Each module has a military role:
- Λ-Core commands.
- Helot labours (resources).
- Agoge trains.
- Krypteia watches.
- Thermopylae holds the last pass.
- Hoplites act.

New components receive Greek names that state their role (Spartanization, ONT-018), for example
Λ-Logos (word, reason) and Mnemosyne (memory).

### IDN-002 · Ethos — adapt, accumulate, evolve; never discard
- **status:** active
- **cites:** INT-005

The project grows by accumulation. Capabilities are extended, made optional or quarantined. They are
not deleted (LAW-001). History is kept and labelled, not rewritten. Superseded reports carry a
historical banner, and superseded decisions are marked `superseded`, never erased.

### IDN-003 · Engineering character — evidence over claims
- **status:** active
- **cites:** INT-002

Status is measured, never asserted. A number in this memory is either recomputed by Mnemosyne
(STATE measures) or anchored to a checkpoint. When a claim and the code disagree, the code is the
evidence and the claim is corrected (PRO-008). The project applies to itself the same standard
SPARTA applies to knowledge: no unverifiable statement is presented as verified.

### IDN-004 · Human–AI relationship — Commander and disciplined hoplites
- **status:** active
- **cites:** INT-001, LAW-008

The project owner is the **Commander** (ONT-017). They decide intention, laws and breaking changes.
AI agents are hoplites. They analyse forensically, propose, implement within the laws, verify and
record. Every change is followed by an update to the memory (PRO-003). Agents never modify core
intention or laws on their own (LAW-005). They surface open questions as decisions for the Commander
(DEC-015).

### IDN-005 · Language and naming conventions
- **status:** active
- **cites:** IDN-001

- Code comments and much of the original documentation are in **Romanian**.
- Status, memory and new technical documents are in **English**.
- Component names are **Greek** or Spartan.

All of these coexist. A document keeps its original language when it is updated. A future
consolidation is planned (EXT-022).

### IDN-006 · Aesthetic — clarity, small explicit modules, honest names
- **status:** active
- **cites:** IDN-003

The project prefers:
- small modules with one military role each;
- explicit wiring (each module receives its own configuration section);
- inspectable mathematics over opaque machinery;
- names that say exactly what a thing does.

For example, `T_Λ^Hybrid` was relabelled when its name ("harmonic mean") did not match its formula
(DEC-015).
